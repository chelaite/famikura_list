# Famikura List

> 非官方的个人购物清单整理工具，面向 ファミクラストア（FAMILY CLUB STORE ONLINE）日本站。
> An unofficial, personal-use shopping list helper for the Japanese Famikura Store.

> **⚠️ 重要声明：** 本项目为非官方的个人开源项目。艺人（含团体及成员）的姓名、肖像、照片及相关作品、商标等，**版权及相关权利均归艺人所属事务所及其他相关权利人所有**。本项目不包含、不提供任何艺人照片或商品图片，详见文末"版权声明与免责声明"。

Famikura List 是一个 Android 应用。你可以把网站购物车的截图交给它，它会自动识别出每件商品的编号和数量，整理成按团体分组、可排序的清单；也可以直接在应用里浏览、搜索商品，加入购物车后生成清单。清单可以导出，也可以分享给其他人。

## 功能

### 1. 截图识别
- 一次选择多张购物车截图，**支持很长的滚动截图**（自动切片识别，重叠区域不会重复计数）。
- 在手机本地用 Google ML Kit 识别日文和数字，**不需要联网，截图不会上传**。
- 提取商品编号（如 `No.HSJ26-435`）和数量，对 O/0、全角/半角、各种横线等常见识别误差做了容错。
- 用截图底部的"商品合計数量"自动核对：识别到的数量合计对得上就视为已核对；对不上会提示"可能漏了几件"。
- 没识别到数量的商品先按 1 计，数量显示为橙色提醒你确认；没有编号的商品单独放一栏，点一下可以补编号。

### 2. 多个列表
- 首页右上角 **＋** 新建列表（先命名，再导入截图）；也可以直接点"导入截图"，识别完成后自动生成列表并命名。
- 所有列表保存在手机本地，关闭应用后仍然保留。
- 长按进入多选：支持**全选、删除、合并、分享**。合并时为新列表命名，**原列表保留**，相同编号的商品数量会相加。
- 列表内可重命名、修改编号/名称/数量、滑动删除。

### 3. 清单整理
- 按团体（编号前缀，如 HSJ）自动分组，组内按系列和序号**升序/降序**切换。
- 每件商品可用 −/＋ 快速调整数量。
- 商品库里有对应商品时，清单中显示缩略图，点击查看大图，方便核对。

### 4. 导出
- 导出 **TXT / Excel（.xlsx）/ PNG 图片**，通过系统分享面板保存到本地或发送给他人。

### 5. 商品库
- 在"商品库"页面选择**团体或个人**，把对应商品同步到手机本地（按 写真 / ミニフォト / ましかくフォト / グッズ / CD・映像・その他 五个类别拉取）。
- 本地搜索商品名、编号和标签，可按类别筛选（注意只能使用日语搜索）；按搜索键可**联网搜索**（网站会匹配商品名和标签，如成员名），搜过的词会记成标签，之后在本地也能搜到。
- 商品图片缓存在手机上，看过一次就不用再下载。
- 浏览商品时可加入购物车，一键生成清单。
- 截图识别出的编号如果在商品库里找得到，会自动换成官方商品名。

### 6. 分享与导入
- 分享列表时，消息前半部分是人能直接看的清单，最后附一段导入代码。
- 收到消息的人复制整条消息，在首页点右上角的导入按钮即可还原列表。

## 使用方法
1. 安装应用后，在首页点"导入截图"，选择购物车截图，识别完成后给列表命名。
2. 检查识别结果：橙色数量需要确认，底部提示和合计数量对不上时请逐项核对。
3. 如需官方名称和缩略图：进入"商品库"（首页右上角商店图标），点同步按钮，勾选团体或个人后开始同步。
4. 在列表页切换升序/降序，调整数量，然后导出或分享。

> 提示：同步商品时每次请求会间隔约 1 秒，选的团体/个人越多耗时越长。

## 已知限制
- 文字识别并不完美：商品名称可能出现错字，数量偶尔会读错，**请务必人工核对**。名称在商品库同步后会自动换成官方名称。
- 编号目前按 `No.字母+数字-数字`（如 `HSJ26-435`）的格式识别，其他格式会进入"无编号商品"。
- 识别截图时依赖网站当前的页面布局，网站改版可能导致识别或同步失效。
- 仅支持日本站，仅提供 Android 版本。

## 隐私与网络
- 不需要注册或登录，不收集任何个人信息。
- 截图识别完全在手机本地进行；列表、商品库数据只保存在手机上。
- 联网时只访问 `famikura-store.jp` 的公开商品列表接口和商品图片，用于同步和搜索商品；分享列表时内容只会发送到你自己选择的应用。
- 应用只申请联网权限，不读取通讯录、位置等信息。
